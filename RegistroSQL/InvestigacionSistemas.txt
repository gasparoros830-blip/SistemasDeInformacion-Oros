Para alojar una base de datos **SQLite** en tu propia computadora y vincularla mediante **Node.js**, el proceso consta de configurar el archivo local de la base de datos y conectarlo a través de un entorno de ejecución en Node.js.

---

Para alojar una base de datos SQLite en tu propia computadora y vincularla mediante Node.js, el proceso consta de configurar el archivo local de la base de datos y conectarlo a través de un entorno de ejecución en Node.js.

---

1. Configurar y alojar SQLite localmente en tu computadora

SQLite no requiere un servidor complejo en ejecución continua, ya que opera directamente sobre un archivo local en tu sistema de archivos. Para instalarlo y crear tu base de datos localmente:

- Instalación de herramientas de SQLite:
  - Windows / macOS / Linux: Descarga el archivo comprimido ejecutable (sqlite-tools) desde la página oficial de SQLite y extráelo en una carpeta de tu preferencia.
  - Linux (vía gestor de paquetes): Se puede instalar directamente ejecutando comandos en la terminal según la distribución, como sudo apt install sqlite3 (Debian/Ubuntu), sudo yum install sqlite (CentOS) o sudo dnf install sqlite (Fedora).

- Creación del archivo de base de datos local:
  - Si ejecutas el comando sqlite3 sin parámetros, SQLite se iniciará en modo de base de datos en memoria temporal, por lo que los datos no se guardarán en el disco.
  - Para crear un archivo persistente en tu equipo, ejecuta el comando indicando el nombre del archivo (por ejemplo, sqlite3 mi_base_datos.db) o utiliza el comando .open --new nombre_archivo.db dentro de la consola de SQLite.

---

2. Vincular la base de datos SQLite con Node.js

Para interactuar con el archivo de la base de datos SQLite desde un proyecto en Node.js:

- Inicialización del proyecto Node.js: Abre la terminal en la carpeta de tu proyecto y ejecuta npm init -y para crear el archivo de configuración package.json.
- Herramientas y ORMs: En el entorno de Node.js y TypeScript, se pueden utilizar herramientas y ORMs como Prisma ORM que soportan SQLite para interactuar con la base de datos.
- Instalación de paquetes: Al igual que con otros gestores de bases de datos, la conexión se realiza descargando los módulos requeridos mediante npm install.

---

Para construir una aplicación con un **formulario web** que agregue y extraiga información de la versión más pequeña de una base de datos SQL (**SQLite**), se utiliza el entorno **Node.js** junto con el paquete `sqlite3`.

---

### 1. Configuración del proyecto y la base de datos

SQLite es una **base de datos ligera y sin servidor** que permite conectar aplicaciones Node.js de forma rápida y sencilla. Para alojarla localmente, se especifica la ruta de un archivo físico de base de datos (por ejemplo, `./database.db`).

* **Inicializar el proyecto**: En la terminal de la carpeta de trabajo, se ejecuta el comando `npm init -y` para generar el archivo de configuración `package.json`.
* **Instalar el módulo de SQLite**: Se instala el paquete ejecutable mediante `npm install sqlite3`.
* **Crear la conexión**: En el script de JavaScript, se importa la librería y se instancia el objeto `sqlite.Database` pasando la ruta del archivo local:
  ```javascript
  import sqlite from 'sqlite3';
  const dbPath = './database.db';
  const db = new sqlite.Database(dbPath);
  ```

---

### 2. Agregar y extraer información en SQLite

Las operaciones CRUD en SQLite se gestionan mediante métodos asíncronos en Node.js:

* **Agregar información (`INSERT`)**: Se utiliza una función asíncrona que ejecuta la sentencia SQL `INSERT INTO` mediante la instrucción `db.run()` pasando los parámetros ingresados:
  ```javascript
  async function insertData(name, email) {
    try {
      await db.run("INSERT INTO users (name, email) VALUES (?, ?)", [name, email]);
      console.log('Datos insertados exitosamente');
    } catch (error) {
      console.error('Error al insertar datos:', error);
    }
  }
  ```
* **Extraer información (`SELECT`)**: Se ejecuta la consulta SQL `SELECT * FROM ...` utilizando el método `db.all()` para consultar todos los registros de la tabla o `db.each()` para procesarlos fila por fila:
  ```javascript
  async function fetchData() {
    try {
      const users = await db.all("SELECT * FROM users");
      console.log('Todos los usuarios:', users);
    } catch (error) {
      console.error('Error al obtener datos:', error);
    }
  }
  ```

### 3. Integración con el Formulario Web (Información fuera de las fuentes)

> **Nota**: *El código para la creación del servidor HTTP con Express y la estructura del formulario HTML no provienen de las fuentes proporcionadas. Esta información se incluye de manera complementaria para completar la arquitectura solicitada y es posible que desees verifiarla de manera independiente.*

#### B. Servidor Web en Node.js (`server.js`)
Configura las rutas para recibir el formulario y realizar la inserción o extracción de datos:
```javascript
import express from 'express';
import sqlite from 'sqlite3';

const app = express();
app.use(express.urlencoded({ extended: true }));

const dbPath = './database.db';
const db = new sqlite.Database(dbPath);

// Ruta para recibir los datos del formulario HTML
app.post('/agregar', async (req, res) => {
  const { name, email } = req.body;
  try {
    await db.run("INSERT INTO users (name, email) VALUES (?, ?)", [name, email]);
    res.send('¡Información agregada con éxito!');
  } catch (error) {
    res.status(500).send('Error al insertar datos');
  }
});

// Ruta para extraer y mostrar la información almacenada
app.get('/usuarios', async (req, res) => {
  try {
    const users = await db.all("SELECT * FROM users");
    res.json(users);
  } catch (error) {
    res.status(500).send('Error al extraer datos');
  }
});

app.listen(3000, () => console.log('Servidor en ejecución en http://localhost:3000'));
```
