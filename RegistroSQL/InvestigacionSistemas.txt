Para alojar una base de datos **SQLite** en tu propia computadora y vincularla mediante **Node.js**, el proceso consta de configurar el archivo local de la base de datos y conectarlo a través de un entorno de ejecución en Node.js.

Para alojar una base de datos SQLite en tu propia computadora y vincularla mediante Node.js, el proceso consta de configurar el archivo local de la base de datos y conectarlo a través de un entorno de ejecución en Node.js.

---

1. Configurar y alojar SQLite localmente en tu computadora

SQLite no requiere un servidor complejo en ejecución continua, ya que opera directamente sobre un archivo local en tu sistema de archivos. Para instalarlo y crear tu base de datos localmente:

- Instalación de herramientas de SQLite:
  - Windows / macOS / Linux: Descarga el archivo comprimido ejecutable (sqlite-tools) desde la página oficial de SQLite y extráelo en una carpeta de tu preferencia.
  - Linux (vía gestor de paquetes): Se puede instalar directamente ejecutando comandos en la terminal según la distribución, como sudo apt install sqlite3 (Debian/Ubuntu), sudo yum install sqlite (CentOS) o sudo dnf install sqlite (Fedora).

- Creación del archivo de base de datos local:
  - Si ejecutas el comando sqlite3 sin parámetros, SQLite se iniciará en modo de base de datos en memoria temporal, por lo que los datos no se guardarán en el disco.
  - Para crear un archivo persistente en tu equipo, ejecuta el comando indicando el nombre del archivo (por ejemplo, sqlite3 mi_base_datos.db) o utiliza el comando .open --new nombre_archivo.db dentro de la consola de SQLite.

---

2. Vincular la base de datos SQLite con Node.js

Para interactuar con el archivo de la base de datos SQLite desde un proyecto en Node.js:

- Inicialización del proyecto Node.js: Abre la terminal en la carpeta de tu proyecto y ejecuta npm init -y para crear el archivo de configuración package.json.
- Herramientas y ORMs: En el entorno de Node.js y TypeScript, se pueden utilizar herramientas y ORMs como Prisma ORM que soportan SQLite para interactuar con la base de datos.
- Instalación de paquetes: Al igual que con otros gestores de bases de datos, la conexión se realiza descargando los módulos requeridos mediante npm install.

---

Guía para conectar una base de datos **SQLite** a un **formulario HTML** utilizando exclusivamente **Node.js**:

---

### 1. Instalación del paquete SQLite
1. Inicializa tu proyecto ejecutando en la terminal:
   ```bash
   npm init -y
   ```
2. Instala el módulo oficial de SQLite para Node.js mediante NPM:
   ```bash
   npm install sqlite3
   ```
  

---

### 2. Conexión a la Base de Datos SQLite e Inserción de Datos

Crea un archivo de JavaScript (por ejemplo, `db.js`) donde importes el paquete, crees la conexión hacia un archivo físico y definas la función que ejecutará la instrucción SQL de inserción:

```javascript
import sqlite from 'sqlite3';

// 1. Conectar a la base de datos en un archivo físico local
const dbPath = './database.db';
const db = new sqlite.Database(dbPath);

// 2. Función asíncrona para insertar los datos en la tabla 'users'
async function insertData(name, email) {
  try {
    await db.run("INSERT INTO users (name, email) VALUES (?, ?)", [name, email]);
    console.log('Datos insertados exitosamente');
  } catch (error) {
    console.error('Error al insertar datos:', error);
  }
}
```

---

### 3. El Formulario HTML y Servidor Web (Información fuera de las fuentes)

> **Nota**: *Las fuentes explican la conexión y las sentencias CRUD en SQLite con Node.js, pero no contienen el código para crear interfaces HTML ni servidores web HTTP. La siguiente integración con un servidor Express se incluye de manera complementaria y puedes verificarla independientemente.*

**A. Formulario HTML (`index.html`):**
Crea una página simple con un formulario que envíe los datos vía método `POST`:
```html
<form action="/guardar" method="POST">
  <input type="text" name="name" placeholder="Tu Nombre" required>
  <input type="email" name="email" placeholder="Tu Correo" required>
  <button type="submit">Enviar</button>
</form>
```

**B. Servidor HTTP en Node.js (`server.js`):**
Recibe la petición HTTP cuando el usuario envía el formulario y llama a la función de la base de datos:
```javascript
import express from 'express';
const app = express();

// Configuración para leer los datos del formulario
app.use(express.urlencoded({ extended: true }));

// Ruta que procesa el envío del formulario
app.post('/guardar', async (req, res) => {
  // Capturar los campos del formulario
  const name = req.body.name;
  const email = req.body.email;

  // Insertar los datos capturados en SQLite
  await insertData(name, email);

  // Responder al navegador
  res.send('¡Datos guardados con éxito en la base de datos SQLite!');
});

app.listen(3000, () => console.log('Servidor corriendo en http://localhost:3000'));
```
